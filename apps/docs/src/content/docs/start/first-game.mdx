The repository has a complete example in [`examples/`](https://github.com/Sifawm/porterkit/tree/main/examples): a counter everyone in the room pushes up to a target. The Admin sets the target and starts the Match, every User clicks `+1`, and the Match ends when the count reaches the target. The code below is that example as it is in the repository.

## Run it

From the root of the repository:

```sh
pnpm install
pnpm dev
```

The server listens on port 3000 and Vite prints the address of the front. After the first login the room id is in the address, after `#`. Open that address in a second tab to join the room as another User.

The same Game drawn by Godot is in `examples/godot`; [Godot](/porterkit/guides/godot/setup/) explains how it is set up.
